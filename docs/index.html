HOW TO READ IT

Signal, not autopilot.

The engine only uses closed M1 candles. Every bot timestamp is UTC and shown above against server, data, and local time. In replay the generated time follows the imported candle instead of today’s clock. Provider-late signals are skipped rather than backdated.
