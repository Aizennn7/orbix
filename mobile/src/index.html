How to make LIVE and ONLINE in Codespace:
1. Create project at supabase.com
2. SQL Editor → run database/schema.sql from root
3. Copy URL + anon key from Project Settings → API
4. cp .env.example .env at root, paste keys, set DATABASE_BACKEND=supabase
5. python scripts/setup_supabase.py --check
6. Rebuild APK → now live online 24/7
